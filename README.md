# Filmes SQL

Meu primeiro projeto prático de SQL: um banco de dados simples com filmes que já assisti, criado para praticar os conceitos que venho estudando na teoria.

## O que o projeto faz

- Cria uma tabela `filmes` com título, ano, diretor e nota
- Insere 5 filmes que já assisti, com a nota que dei para cada um
- Faz consultas para responder perguntas como:
  - Quais filmes eu avaliei acima de 9?
  - Qual filme tem a maior nota?
  - Qual a média das minhas notas?
  - Quantos filmes eu tenho de cada diretor?

## Tecnologias

- SQL (SQLite)

## Conceitos praticados

- `CREATE TABLE`
- `INSERT INTO`
- `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`
- Funções de agregação: `COUNT`, `AVG`
- `GROUP BY`
